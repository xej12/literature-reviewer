# 使用指南

[返回首页](../README.md) · [安装指南](installation.md) · [故障排查](troubleshooting.md)

## 先选一篇带 PDF 的论文

启动后，左侧是 Zotero 集合，中间是文献列表。支持搜索标题或摘要、按分析状态筛选以及按阅读等级排序；点开卡片进入该论文的详情页。

列表会保守合并可识别的重复记录，优先展示带可用本地 PDF 的记录，只影响本工具的显示，不会删除或合并 Zotero 原条目。修改 Zotero 后，点击“刷新文献库”。

“打开 PDF”直接打开原始文件；“划词阅读 PDF”使用内置阅读器，可以选中文字。没有可用 PDF 时先去 Zotero 检查附件是否已下载、链接文件是否被移动；只有元数据的论文不能凭空生成全文深读。

## 按问题阅读，避免一次生成所有内容

1. 点“论文深度解读”，先看材料覆盖情况。
2. 只在需要时点击“生成本章”。可以先生成阅读导览，再根据疑问选方法、公式、实验结论或局限；不会自动把所有章节生成一遍。
3. 阅读时区分原文事实、背景教学和推断。点击来源查看提取片段，对照 PDF 页码核实；这里的页码按 PDF 实际页序，不一定等于论文印刷页码。
4. 看公式时展开原文对照；文字提取无法保留的符号应回到 PDF 查看，勿只凭模型转写理解原式。
5. 关闭后再打开同一篇文章和章节，可直接看已保存讲解。若材料版本变化，先查看旧版本记录，再决定是否生成新版。

扫描 PDF 没有文字层时，全文解读可能无法进行；当前没有 OCR。长文可能只使用全文范围内选取的部分片段，界面会显示覆盖情况。

## 专业术语与翻译

- **个人术语表：** 记录习惯使用的专业译名和领域说明。内置的少量示例不是完整权威词典，可以修改补充。
- **术语精讲：** 直接输入不懂的术语，按需生成它在本文中的含义、前置概念、机制、公式或例子；无需先付费提取整篇术语。
- **划词翻译：** 在内置 PDF 阅读器或支持划词的文字区域选中词句，再点“翻译”。选中本身不调用模型。精确命中个人术语表免费，其他翻译按缓存和模型配置处理。

修改术语表会影响之后的生成与翻译，但不会自动改写已保存讲解。没有文字层的扫描 PDF 暂不支持划词翻译。

## 图表精讲

先安装 Poppler，并配置支持图片输入的模型。在文献详情点“图表解析”，左侧查看 PDF，右侧读讲解。先定位页码，放大确认图中文字；复杂页面优先框选单个图表，再生成。

模型只接收当前选区/页面图片及标题，并未在这个功能中获得全文；图上看得见的内容、补充背景和推断应分别看待。看不清的数值需要在原 PDF 核对，不能把推断当成作者结论。

关闭解析窗口会取消该窗口正在进行的生成，本电脑也会关闭上游连接。已经生成的用量无法退回；服务商是否立即停止远端计算取决于其实现。

## 期刊指标与阅读优先级

安装指南中的期刊数据导入是可选步骤。数据采用固定年份的中科院/JCR 表，不是官方实时查询；缺少分区不等于论文不重要。列表可按“有分区信息 / 暂无分区信息”浏览。

先设置自己的研究目标与中英文关键词，再选择要评估的文章。“夯 → 顶级 → 人上人 → NPC → 拉”表示**对你当前目标的阅读优先级**。相关性和内容是主要依据，期刊指标只占参考部分；也可以免费手动调整等级及理由。

修改研究目标后旧评估仍保留，但不会直接作为新目标下的有效评分。引文无法在材料中核实时，保留答复并标为待评估，不自动反复调用模型。

## 我的笔记：从阅读到自己的理解

左栏“我的笔记”集中管理手写笔记，“最近笔记”可以快速回到上次内容。点“新建笔记”选择快速摘记、论文精读、图表研读或空白模板；模板中的问题和提示文字都可以自行改写、删除。

从文献详情的“写笔记 / 查看笔记”进入，可查看并新建关联该文献的笔记。关联信息保存在笔记中，导出时带上标题、作者、来源、DOI（如有）和 Zotero 条目键；不会写回 Zotero 原库。也可直接在笔记中心创建独立笔记。

编辑区使用 Markdown，工具栏可插入标题、粗体、列表、引文和公式。点“预览”查看排版，大屏“对照”可同时编辑与预览。输入后约 0.7 秒开始自动保存，也可点“立即保存”或 Ctrl/⌘+S；以“已保存到本电脑”为准。笔记搜索覆盖标题、正文及关联论文标题。

打开笔记后，右上方“删除笔记”会先询问确认。确认后删除正文及浏览器未保存草稿，并更新列表和最近笔记；不会删除关联文献或 PDF。应用内无法恢复已删除笔记，需保留时请先导出。如果其他窗口刚修改过该笔记，本次删除会被阻止，避免误删新内容。

如果两个窗口同时修改同一笔记，过期版本会被拒绝。未保存内容在浏览器可用的本地存储中暂存；遇到冲突先导出草稿，再点“载入已存版本”。浏览器存储并非正式备份，清除站点数据会清除草稿。笔记功能无需配置模型，全部操作不消耗 Token。

导出可选 Markdown（继续编辑）和 HTML（离线阅读）。HTML 公式使用 MathML，由现代浏览器显示；可点“打印 / 存为 PDF”，在浏览器打印窗口选择“另存为 PDF”。本版没有 DOCX、图片附件、自定义模板或跨设备同步；Markdown 图片引用不自动加载，正文中的 HTML 也不执行。

## 哪些操作会消耗 API 额度

| 操作 | 是否调用模型 |
| --- | --- |
| 浏览、搜索、刷新 Zotero、打开 PDF | 否 |
| 创建/编辑笔记、模板、搜索、预览和导出 | 否 |
| 查看已存讲解、旧版本、翻译缓存 | 有匹配缓存时否 |
| 修改个人术语、手动等级、研究目标 | 否 |
| 免费“重新整理已存答复” | 否；只处理本电脑已有内容 |
| 首次生成章节/术语/图表，提取术语、模型优先级评估 | 是；已有有效缓存时复用 |
| 点击翻译 | 术语表精确命中或缓存命中时否；否则是 |
| 确认重新生成或重新翻译 | 是 |
| 测试连接 | 是；会发起真实小请求 |
| 导入期刊数据 | 不调用模型；从 GitHub 下载数据 |

模型的价格和最终用量由你配置的服务商决定。此项目不提供免费 API 额度。格式出错时先查看已有正文或免费整理，不要立即连续点重新生成。

## 备份、更新与卸载

程序文件和个人数据是两件事。GitHub 上的代码备份**不包含**本电脑的 `data/`，也不包含 Zotero 文献库。

| 内容 | 本电脑位置 |
| --- | --- |
| 模型地址、模型名称、明文 API Key | `data/settings.json` |
| 图表、旧版摘要/术语与历史记录 | `data/analysis/` |
| 我的手写笔记、模板标识及关联文献信息 | `data/notes/` |
| 深读章节与历史 | `data/deep-reading/` |
| 术语精讲 | `data/term-reading/` |
| 翻译缓存、个人术语表 | `data/translations/`、`data/terminology.json` |
| 研究目标与阅读优先级 | `data/research.json`、`data/reading-priority/` |
| 本电脑导入的期刊表 | `data/journals/` |
| 原论文、附件和 Zotero 数据库 | Zotero 自己的数据目录；不在本项目内 |

**备份：** 停止服务后，将整个 `data/` 复制到自己的安全备份位置。它包含密钥和可能受版权保护的材料，不能上传公开仓库、Issue 或网盘公开链接。Zotero 文献库需要另外备份。

**ZIP 更新：** 停止旧服务，备份 `data/`；将新版 ZIP 解压到新目录，复制自己的 `data/`，按安装指南重新创建 `.venv`、安装依赖。检查 Zotero 自定义环境变量仍有效，再启动。不要直接覆盖后删除唯一旧副本；不要从他人那里接收包含密钥的 `data/`。

**Git 更新：** 停止服务并备份 `data/`；若没有本地代码改动，可 `git pull --ff-only`，然后用项目 Python 重新安装 `requirements.txt`。如果提示冲突或分支分叉，先保留本地改动，不要强制重置。

**卸载：** 停止服务后删除项目目录即可；这会删除其中未备份的解读和设置，不会删除 Zotero 原文献。需要保留解读时先备份。
