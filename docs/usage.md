# 使用指南

[返回首页](../README.md) · [安装指南](installation.md) · [故障排查](troubleshooting.md)

## 第一次打开怎么开始

首次进入网页会显示三步提示。先在 Zotero 中确认一篇本地 PDF，再点击“刷新文献库”；确认能打开原始 PDF 后，在“模型设置”填写自己的 API。右上角的状态会显示当前连接的是 Zotero 还是示例模式。示例模式只用于体验界面，不读取个人文件，也不会发送模型请求。

## 先选一篇带 PDF 的论文

启动后，左侧“阅读工作台”提供文献库、我的笔记、我的卡片和联合查找入口。点击“文献库”展开 Zotero 集合，再次点击收起；集合和刷新入口都在文献库导航中。中间是文献列表，支持搜索标题或摘要、按分析状态筛选以及按阅读等级排序；顶部显示分析进度，底部可分页。点开文献进入独立详情页，阅读工具、摘要、期刊指标和附件分区展示。

列表会保守合并可识别的重复记录，优先展示带可用本地 PDF 的记录，只影响本工具的显示，不会删除或合并 Zotero 原条目。修改 Zotero 后，点击“刷新文献库”。

“打开 PDF”直接打开原始文件；“划词阅读 PDF”使用内置阅读器，可以选中文字。没有可用 PDF 时先去 Zotero 检查附件是否已下载、链接文件是否被移动；只有元数据的论文不能凭空生成全文深读。

## 按问题阅读，避免一次生成所有内容

1. 点“论文深度解读”，先看材料覆盖情况；点击“正文材料”展开具体页码范围，材料有缺失时摘要行会提示。左侧目录显示当前已保存的章节数，目录和正文可分别滚动；窄屏目录改为横向浏览。
2. 只在需要时点击“生成本章”。可以先生成阅读导览，再根据疑问选方法、公式、实验结论或局限；不会自动把所有章节生成一遍。
3. 阅读时区分原文事实、背景教学和推断。点击来源查看提取片段，对照 PDF 页码核实；这里的页码按 PDF 实际页序，不一定等于论文印刷页码。
4. 看公式时展开原文对照；文字提取无法保留的符号应回到 PDF 查看，勿只凭模型转写理解原式。
5. 关闭后再打开同一篇文章和章节，可直接看已保存讲解。若材料版本变化，先查看旧版本记录，再决定是否生成新版。

扫描 PDF 没有文字层时，全文解读可能无法进行；当前没有 OCR。长文可能只使用全文范围内选取的部分片段，界面会显示覆盖情况。

## 专业术语与翻译

- **个人术语表：** 记录习惯使用的专业译名和领域说明。内置的少量示例不是完整权威词典，可以修改补充。
- **术语精讲：** 直接输入不懂的术语，按需生成它在本文中的含义、前置概念、机制、公式或例子；无需先付费提取整篇术语。
- **划词翻译：** 在内置 PDF 阅读器或支持划词的文字区域选中词句，再点“翻译”。选中本身不调用模型。精确命中个人术语表免费，其他翻译按缓存和模型配置处理。

修改术语表会影响之后的生成与翻译，但不会自动改写已保存讲解。没有文字层的扫描 PDF 暂不支持划词翻译。

## 图表精讲

先安装 Poppler，并配置支持图片输入的模型。在文献详情点“图表解析”，左侧查看 PDF，右侧读讲解。先定位页码，放大确认图中文字；复杂页面优先框选单个图表，再生成。

大屏中原图和解析分别滚动，解析按钮与本页保存记录保留在右栏上方。原图左右两侧可以翻页，工具栏可输入页码、缩放、适应宽度或打开原图。窄屏自动上下排列，向下滚动查看解析。

模型只接收当前选区/页面图片及标题，并未在这个功能中获得全文；图上看得见的内容、补充背景和推断应分别看待。看不清的数值需要在原 PDF 核对，不能把推断当成作者结论。

关闭解析窗口会取消该窗口正在进行的生成，本电脑也会关闭上游连接。已经生成的用量无法退回；服务商是否立即停止远端计算取决于其实现。

## 期刊指标与阅读优先级

安装指南中的期刊数据导入是可选步骤。数据采用固定年份的中科院/JCR 表，不是官方实时查询；缺少分区不等于论文不重要。列表可按“有分区信息 / 暂无分区信息”浏览。

先设置自己的研究目标与中英文关键词，再选择要评估的文章。“夯 → 顶级 → 人上人 → NPC → 拉”表示**对你当前目标的阅读优先级**。相关性和内容是主要依据，期刊指标只占参考部分；也可以免费手动调整等级及理由。

修改研究目标后旧评估仍保留，但不会直接作为新目标下的有效评分。引文无法在材料中核实时，保留答复并标为待评估，不自动反复调用模型。

## 发现相关文献

在一篇论文详情点击“查找相关文献”，进入独立页面，再点“开始查找”。网站会从 OpenAlex 和 Semantic Scholar 查询相似研究、前置文献和后续研究，合并去重后展示最多 20 篇；每项都标明数据来源和关系依据，可打开 DOI/原文及数据源提供的开放获取链接。结果不是完整引文列表，也不是对论文全文的质量评价。

可按三类关系筛选、隐藏库内已有文献，或打开已经存在于库内的论文。有 DOI 时优先准确定位；无法准确匹配时会列出起始论文候选，核对作者、标题及年份后点“确认是这篇”。确认后只使用该数据源查询，防止不同数据源匹配到了不同论文。

检索无需配置大模型，不消耗模型 Token，也不上传 PDF；查询可能向学术服务发送 DOI、标题及摘要。数据源鉴权、限流或语义检索不可用时，页面会显示提示；关键词降级会明确标注。“检索设置”中可分别填写 OpenAlex/Semantic Scholar Key，与模型 API Key 不同。留空保留已存 Key，勾选清除后保存才删除。服务自身的配额由其提供方决定。

结果保存在本电脑，下次打开直接读取，不会自动联网刷新；元数据变化时会提示旧结果。主动刷新失败且未取得新结果时保留旧结果。可点“停止检索”或返回起始论文，中止仍在进行的请求；已完成请求使用的服务额度无法退回。当前不包含图谱和一键导入。

### 联合查找：围绕研究问题扩展阅读

左栏“联合查找”中，从已导入文献里选 **2–5 篇不同论文**，填写研究问题，再点“查找 / 更新”。也可从单篇相关文献页面点“用这篇论文联合查找”。搜索框查找标题或摘要，重复记录优先展示带 PDF 的条目；选定后可移除或继续添加。

研究问题单独向两个学术来源查询，并与每篇起始论文的相似、前置、后续结果合并。至少两篇在 Semantic Scholar 准确匹配时，还会尝试其多篇正例推荐。中文问题会参考本电脑专业术语表和“研究方向”的中英文同义词展开；**英文检索词优先**。未收录的专业中文问题建议补充英文词，系统不会调用大模型翻译或判断相关性。

最多展示 60 篇候选，按问题检索命中、标题 / 摘要词语命中、独立关联的起始论文数及数据源排名排序。每项标明具体关联起点、来源和关系；“多篇联合推荐”本身不计为与每篇均有独立关联，不生成未经核对的相关性百分比。起始论文不出现在推荐列表；缺少准确匹配时，可在下方数据源状态中进入单篇页面核对候选，再主动更新联合检索。

年份、仅综述、仅开放获取、关联类型、隐藏库内已有文献筛选都只作用于已取回的候选，不额外联网。缺少对应元数据的论文不会通过该项筛选；这不是对整个学术数据库的完整过滤。“不感兴趣”只影响本组结果，勾选“显示不感兴趣”可恢复，不训练模型或自动影响其他检索。

检索自动保存在本电脑，右侧“已保存检索”展示最近 20 组，可直接重开。修改表单时下方仍显示上次结果，点击查找才使用新条件；相同论文组合、问题与检索词复用同一组记录。已存单篇数据会复用，主动更新同组时才刷新；若部分单篇数据过期，会明确提示。停止或离开页面会发送取消请求，已完成的单篇查询可能已保存，已消耗的服务额度无法退回。

正式结果和反馈位于 `data/discovery/groups/`，随 `data/` 一起备份。未提交表单保存在当前浏览器站点存储中，清除站点数据会移除草稿，不会删除服务器端已存结果。此功能不读取模型 Key，也不写入 Zotero。

### 挑选推荐论文并导出

单篇、联合查找页面中，每张候选卡片上方的“选入导出清单”用于勾选；结果上方可“勾选当前显示”或“清空勾选”，然后选择格式并下载。筛选时保留已有勾选，工具栏明确显示被筛选隐藏的已选数量；下载包含这些隐藏的已选论文。“不感兴趣”的文献不参与导出，恢复后需重新勾选。离开、重开或刷新页面会清空勾选，不删除保存的检索结果。

| 导出格式 | 用途与内容 |
| --- | --- |
| RIS `.ris` | 在 Zotero 中选择“文件 → 导入”，选择下载的文件；包含标题、完整作者、年份、来源、DOI、原文链接及摘要（如数据源提供） |
| BibTeX `.bib` | 可用于 BibTeX / BibLaTeX，包含已有引用元数据与稳定的引用键；作者按完整姓名保留，不推断姓氏 |
| Markdown `.md` | 包含研究问题、起始论文、检索时间、原文链接、关联依据、摘要和阅读笔记模板，可继续编辑 |

RIS / BibTeX 使用通用条目类型（`GEN` / `@misc`），不凭来源名称猜测是期刊、会议或图书；缺失年份、卷期、页码等不补造。导入后可根据原文更正文献类型、作者姓名结构及缺失信息。文件使用 UTF-8，中文和特殊符号会保留；BibTeX 标题中的 TeX 特殊字符会转义。

导出只读取本电脑已有检索，不会重新联网或调用模型，也不会自动导入 Zotero。若其他窗口刷新后部分已选文献已经消失，会提示重新打开结果再勾选，不会悄悄换成别的论文。下载文件由浏览器保存到下载位置，下载列表或浏览器设置中可以查看；它们不自动保存在项目 `data/` 中。Zotero 自己的导入去重行为需在导入后核对。

## 我的笔记：从阅读到自己的理解

左栏“我的笔记”集中管理手写笔记，列表按最近修改排序；点击已有笔记继续编辑。点“新建笔记”再点“新建空白笔记”，直接写自己的内容，不预设模板。窄屏时笔记列表改为横向浏览。

从文献详情的“写笔记 / 查看笔记”进入，可查看并新建关联该文献的笔记。关联信息保存在笔记中，导出时带上标题、作者、来源、DOI（如有）和 Zotero 条目键；不会写回 Zotero 原库。也可直接在笔记中心创建独立笔记。

编辑区使用 Markdown，工具栏可插入标题、粗体、列表、引文和公式。点“预览”查看排版，大屏“对照”可同时编辑与预览。输入后约 0.7 秒开始自动保存，也可点“立即保存”或 Ctrl/⌘+S；以“已保存到本电脑”为准。笔记搜索覆盖标题、正文及关联论文标题。

打开笔记后，右上方“删除笔记”会先询问确认。确认后删除正文及浏览器未保存草稿，并更新列表和数量；不会删除关联文献或 PDF。应用内无法恢复已删除笔记，需保留时请先导出。如果其他窗口刚修改过该笔记，本次删除会被阻止，避免误删新内容。

如果两个窗口同时修改同一笔记，过期版本会被拒绝。未保存内容在浏览器可用的本地存储中暂存；遇到冲突先导出草稿，再点“载入已存版本”。浏览器存储并非正式备份，清除站点数据会清除草稿。笔记功能无需配置模型，全部操作不消耗 Token。

导出可选 Markdown（继续编辑）和 HTML（离线阅读）。HTML 公式使用 MathML，由现代浏览器显示；可点“打印 / 存为 PDF”，在浏览器打印窗口选择“另存为 PDF”。本版没有 DOCX、图片附件、自定义模板或跨设备同步；Markdown 图片引用不自动加载，正文中的 HTML 也不执行。

## 我的卡片：保存选段，再主动提问

阅读解读或内置 PDF 时划选文字，菜单竖向显示“翻译、存入笔记、存入卡片”；选段靠近屏幕底部时，菜单整体移到上方。点击“存入卡片”后会显示保存结果，成功后可到左侧“我的卡片”查看。

卡片以网格展示，封面区分待理解摘录和已整理总结，并保留来源、日期和删除入口。点开卡片，分别查看保存的原文、问答与总结。自己输入问题后点击“发送问题”才调用模型；打开卡片不会自动提问。想整理对话时点击“总结当前内容”，也可以直接修改总结并点“保存修改”；总结的状态提示显示在总结编辑区旁。保存后的总结会显示在卡片表面。

卡片和笔记分开保存。浏览、保存摘录、手动修改总结和删除不调用模型；发送问题或生成总结会调用你配置的模型。删除前会询问确认，应用内不能恢复，重要内容请先备份。

## 哪些操作会消耗 API 额度

| 操作 | 是否调用模型 |
| --- | --- |
| 浏览、搜索、刷新 Zotero、打开 PDF | 否 |
| 创建/编辑笔记、搜索、预览和导出 | 否 |
| 保存/浏览卡片、手动修改总结、删除卡片 | 否 |
| 发送卡片问题、生成卡片总结 | 是 |
| 查找相关文献、读取已有检索结果、勾选并导出 | 否；仅主动联网检索会使用学术数据服务额度 |
| 查看已存讲解、旧版本、翻译缓存 | 有匹配缓存时否 |
| 修改个人术语、手动等级、研究目标 | 否 |
| 免费“重新整理已存答复” | 否；只处理本电脑已有内容 |
| 首次生成章节/术语/图表，提取术语、模型优先级评估 | 是；已有有效缓存时复用 |
| 点击翻译 | 术语表精确命中或缓存命中时否；否则是 |
| 确认重新生成或重新翻译 | 是 |
| 测试连接 | 否；只检查服务的 `/models` 接口，部分服务可能不提供 |
| 导入期刊数据 | 不调用模型；从 GitHub 下载数据 |

模型的价格和最终用量由你配置的服务商决定。此项目不提供免费 API 额度。格式出错时先查看已有正文或免费整理，不要立即连续点重新生成。

## 备份、更新与卸载

程序文件和个人数据是两件事。GitHub 上的代码备份**不包含**本电脑的 `data/`，也不包含 Zotero 文献库。

| 内容 | 本电脑位置 |
| --- | --- |
| 模型地址、模型名称 | `data/settings.json` |
| 加密后的模型 API Key | `data/model-key.bin`（Windows 当前账户 DPAPI） |
| 图表、旧版摘要/术语与历史记录 | `data/analysis/` |
| 我的手写笔记、模板标识及关联文献信息 | `data/notes/` |
| 阅读卡片、对话与总结 | `data/cards/` |
| 相关文献结果、匹配确认与查询时间 | `data/discovery/` |
| 检索服务明文 API Key | `data/discovery-settings.json` |
| 深读章节与历史 | `data/deep-reading/` |
| 术语精讲 | `data/term-reading/` |
| 翻译缓存、个人术语表 | `data/translations/`、`data/terminology.json` |
| 研究目标与阅读优先级 | `data/research.json`、`data/reading-priority/` |
| 本电脑导入的期刊表 | `data/journals/` |
| 原论文、附件和 Zotero 数据库 | Zotero 自己的数据目录；不在本项目内 |

**备份：** 在右上角“模型设置”点击“导出本地备份”，或停止服务后将整个 `data/` 复制到自己的安全备份位置。网页导出的 ZIP 不包含 API Key、Zotero 数据库或 PDF；手动复制的 `data/` 仍可能包含检索服务 Key 和受版权保护的材料，不能上传公开仓库、Issue 或网盘公开链接。Zotero 文献库需要另外备份。

**ZIP 更新：** 停止旧服务，备份 `data/`；将新版 ZIP 解压到新目录，复制自己的 `data/`，按安装指南重新创建 `.venv`、安装依赖。检查 Zotero 自定义环境变量仍有效，再启动。不要直接覆盖后删除唯一旧副本；不要从他人那里接收包含密钥的 `data/`。

**Git 更新：** 停止服务并备份 `data/`；若没有本地代码改动，可 `git pull --ff-only`，然后用项目 Python 重新安装 `requirements.txt`。如果提示冲突或分支分叉，先保留本地改动，不要强制重置。

**卸载：** 停止服务后删除项目目录即可；这会删除其中未备份的解读和设置，不会删除 Zotero 原文献。需要保留解读时先备份。
