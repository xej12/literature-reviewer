# 功能细节与实现边界

[返回首页](../README.md) · [使用指南](usage.md) · [故障排查](troubleshooting.md)

本文记录缓存、材料覆盖、来源定位和模型兼容等细节；首次使用请先阅读安装指南。

## 期刊数据与阅读优先级

数据参考 [ShowJCR](https://github.com/hitfyd/ShowJCR)，固定版本为中科院 2025 / JCR 2025 CSV。匹配适配器独立实现，未复制上游 GPL 插件代码。第三方数据保留在本机，不随本仓库重新分发；使用前请了解上游数据来源及适用条件。其他调研参考：[cas-journal-mcp](https://github.com/Cuberskyleaf/cas-journal-mcp)、[zotero-style](https://github.com/MuiseDestiny/zotero-style)、[zotero-publication-rankings](https://github.com/ben-AI-cybersec/zotero-publication-rankings)。其中 SJR 分区不能替代 JCR。

首次使用可导入数据（固定提交、文件名和 SHA256 见 `references/journal-data.json`）：

```powershell
python scripts/import_journals.py
```

已有上述两份 CSV 时可运行 `python scripts/import_journals.py --from-dir "CSV所在目录"`。校验不符则拒绝导入。数据未载入时网页会提示，其他功能仍可使用。

页面标注的是**数据表年度**，不是论文发表时的指标，也不是直接连接官方实时服务。ISSN 优先，其次精确匹配规范刊名；未匹配的 ISSN 不回退到可能冲突的刊名。歧义、不适用和未收录分别呈现，全部学科分区可在详情展开查看。

文献列表提供“有分区信息”和“暂无分区信息”两类切换，并显示篇数。存在有效中科院大类/小类 1–4 区，或 JCR 学科 Q1–Q4 即归入前者；只有 IF、刊名匹配但没有分区的归入后者。分类是本工具的视图，不改写 Zotero 集合，支持与搜索、分析状态、等级筛选和排序组合使用。

先在网页设置研究目标与中英文关键词。关键词只作相关性线索，不自动判定必读。点击“评估阅读优先级（消耗 Token）”才调用模型，材料包括元数据、摘要、可提取 PDF 前 12 页（最多 40000 字符）与已保存解读，不保证覆盖全文。模型必须提供可在原文核对的引文，并说明材料限制。相关性占 60 分，内容价值占 30 分，期刊参考最多 10 分；缺少指标时按内容得分归一化，不因无 IF 自动降级。材料不足保持待评估。

结果按文献内容和研究目标版本缓存，浏览和排序不调用模型。修改目标或文献摘要/解读后旧结果保留但不套用。支持免费手动设定等级和理由；重新模型评估会替换当前等级，按钮提示 Token 消耗。未评估文献放在已评估等级后，按相关主题线索辅助排序。等级仅指对个人研究目标的阅读优先级，不是论文质量定论。

评估时将原文片段编号，模型引用片段 ID 后由程序还原引文，避免抄写和翻译造成匹配失败。兼容旧式字符串或引文对象，以及 PDF 断行、断词、连字等格式差异；不接受修改词义、数字或否定词的模糊匹配。部分引文有效时仅保留有效部分；没有可核实引文时仍缓存模型答复，标为“待评估”，不采用其分数，也不自动再次调用模型。可以查看已保存答复或免费手动调整。

## 按需论文深读

在文献详情点击“论文深度解读”（已有结果时为“查看论文解读”），依次按需生成阅读导览、方法拆解、公式讲解、实验与结论、局限与自检。打开页面、查看原文、切换章节和查看缓存都不会调用模型；只有点击“生成本章”或确认“重新生成本章”才调用已配置的服务。模型最长可等待 600 秒。不会自动重试或自动生成其他章。

深读独立于旧版摘要与术语/图表功能：旧版解读仍可在章节菜单查看。新结果保存在本机 `data/deep-reading/`，按 PDF 提取内容和解释规范版本匹配；章节逐项保存，重新生成前一版及 PDF 旧版本仍保留。PDF 更换后不会悄悄重用旧解读，可以在“材料版本”查看已存版本。

读取所有 PDF 页的可提取文字，而非只读前 12 页。普通长度全文直接送入模型；超过每章约 90000 字符的预算时，在全文范围选取页面代表片段与本章相关片段，并显示实际覆盖页码和未包含片段。无法提取正文的文献暂停生成。扫描件 OCR 与从原图可靠识别公式尚未实现；正文提取可能损坏双栏顺序、数学符号和上下标，需要打开原 PDF 核对。

讲解区分论文原文、补充背景/教学例子、分析推断/建议。来源编号由程序解析为真实 PDF 页序和原文片段，不让模型自行填写页码；编号匹配只验证定位存在，不能保证模型解释正确。来源编号无效的内容会保存并提示待核对，不自动花费 Token 重试。

工作流参考 [DeepPaperNote](https://github.com/917Dhj/DeepPaperNote) 的证据组织、机制解释与材料覆盖原则，在本应用内独立实现，没有运行其 Obsidian/Agent 流程。公式使用本地 [KaTeX 0.16.22](https://github.com/KaTeX/KaTeX/releases/tag/v0.16.22)，MIT 许可证随 `web/vendor/katex/LICENSE` 保留，仅包含浏览器使用的 woff2 字体，无需连接 CDN。未集成许可证未明确的 PaperForge 源码或提示词。

论文深读和术语精讲中的独立公式下方提供原文对照：按引用片段中的公式编号寻找所在页，展开查看原 PDF 页面，或点击“放大阅读”直接跳到该页。页码使用 PDF 实际页序；编号匹配仅用于导航，不能证明模型转写正确。没有明确编号时显示引用的候选页，教学公式另行标识。旧讲解中误写成字面 `\n` 的换行会在显示时保守修复，保留 `\nu`、`\nabla` 等合法命令，不改写缓存、不调用模型。新生成要求保留原式符号与编号、逐项解释符号/单位/条件；提取损坏时明确指出，不猜写原式。

模型答复先在本机保存，再进行章节解析。支持本地修复代码围栏、前后说明、字符串换行、尾逗号和 LaTeX 反斜杠转义，不会补写缺失的结论、公式或引文。被服务长度限制截断的答复不作为完整章节采用；无法整理的答复标为“待整理”，可免费查看原始正文，点击“重新整理已存答复（免费）”也不会调用模型。只有明确确认重新生成才再次调用模型。历史上旧代码没有保存的失败答复无法恢复。接口 `repairOnly:true` 即使没有待整理答复也禁止调用模型。

输出预算默认跟随模型服务，不再固定为 8000。可在“模型设置 → 论文深度解读”填写单次预算，留空恢复自动。预算包含服务计入的思考与正文 Token，按实际用量计费；思考模式可能在写出正文之前用完较小的预算。仅对 DeepSeek 官方 `deepseek-flash` / `deepseek-v4-pro` 适配 JSON 模式与可选思考强度参数，其他兼容服务不接收这些专有参数。根据 [DeepSeek API 文档](https://api-docs.deepseek.com/api/create-chat-completion)及[思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode)（2026-10-18 核对），默认开启思考、强度 high，自动输出预算为 64K，最大思考为 128K，关闭思考为 8K；实际行为以服务为准。应用只记录用量数字和是否存在思考内容，不保存或展示模型的内部思考链。正文为空时明确显示“未生成正文”，不再提供无法产出正文的免费整理按钮。

## 专业术语与划词翻译

文献详情新增“划词阅读 PDF”：以原始版式显示 PDF，选中词句后点“翻译”。标题、摘要、解读与原文引文中也支持划词。原有“打开 PDF”仍直接打开原文件。扫描页没有文字层时暂不支持划词 OCR。

“专业术语表”记录个人采用的专业译名与领域说明，初始加入用户确认的 `coronagraph → 日冕仪`，可免费增补和修正。后续论文解读、术语解释、图表解析与划词翻译共用这些约定；原有解读不会自动重新生成。

精确命中术语表免费；其他词句使用现有模型配置，结合论文和上下文翻译。模型译文按文献保存在 `data/translations/`，相同原文、上下文及术语版本直接复用。划词和打开术语表不会调用模型；主动重新翻译需确认。个人术语文件与翻译缓存不上传 GitHub。译文会区分专业解释和不确定性，保留英文供核对；专业正确性仍需研究者判断。

实际集成 [Mozilla PDF.js](https://github.com/mozilla/pdf.js) 5.4.149（Apache-2.0）；参考 Zotero PDF Translate 与 NextAI Translator 的交互设计，未复制其源码。调研选择与实现范围见 [翻译方案记录](../references/translation-research.md)。

## 按需术语精讲

文献详情的“术语精讲”、短定义卡片的“打开术语精讲”、划词翻译面板的“结合本文打开术语精讲”可进入同一阅读界面。可以直接输入术语，无需先付费提取整份术语列表。打开、输入/选择术语、查询已存讲解都不调用模型，点击“讲透这个术语（消耗 Token）”才生成一个术语。

讲解覆盖专业译名、前置概念、工作机制、本文作用、教学例子/必要公式、相近概念区别、适用条件与自检问答，依实际材料展开。复用论文深读的来源编号、公式排版、原始答复保留与本地格式整理。区分论文事实、补充背景和推断，不将教学数值当成论文实验结果。模型教学深度与正确性仍需研究者结合原文检查。

全文范围内优先选取术语及其别名的出现片段、相邻上下文，再补入页面代表片段；单个术语材料约 60000 字符上限，界面显示实际材料覆盖、术语文字匹配页与未匹配提示。文字匹配仅作定位，可能涉及参考文献，不证明作者在正文使用或验证了该概念。原有短定义提取功能保持单独使用，仍有其材料范围限制。

结果独立保存在 `data/term-reading/<文献键>.json`，每个术语单独缓存，PDF 或个人术语表版本变化后保留旧版本供查看。重新生成需确认，原先成功讲解保留为历史；格式失败保留原始答复，可免费本地整理；无待整理内容时也不因整理操作调用模型。深读预算设置同时适用于术语精讲，不自动生成其他术语。

## 图表精讲

在“图表解析”中框选图表或选择整页，再点击精讲。新生成按内容解释读图顺序、坐标与单位/刻度/图例、各曲线/子图/表格行列、可能机制、证据边界与自检问答；流程图与光路图沿箭头解释部件及输入输出。图片直接可见内容、补充教学和推断分别标识，并显示具体图中位置。公式与论文深读共用本地排版。该功能只将当前页面或选区图片和标题交给模型，不以未提供的全文支持结论；看不清的符号和数值应明确标记，视觉识别仍需读者核对。

旧版四卡片结果仍可免费查看；不会自动付费升级。重新解析需确认，成功后保留历史，格式失败则保留旧结果和已返回正文，支持“重新整理已存答复（免费）”。待整理答复、历史解析和尝试记录保存在本机原有 `data/analysis/` 缓存中的 `figureDrafts`、`figureHistory` 和 `figureAttempts`。图表使用模型设置中的输出预算；需要支持图片输入的模型。仅点击精讲/重新解析才可能调用模型，免费整理无待整理答复时也不调用。

阅读界面会在本地将旧答复的长段按已有句子分段，将有编号的长公式独立排版，自检题与答案分别显示为卡片；不会重新调用模型或改写缓存。新生成也要求段落、公式、符号解释与问答分开组织。

关闭解析窗口（叉号或遮罩）、离开当前文献或切换到其他解析时，会取消该窗口正在进行的论文深读、术语精讲、术语提取或图表解析请求。浏览器中断等待，同时通过独立取消接口让服务器关闭上游模型连接；排队及尚未发送的请求取消后不再调用模型。已有成功结果保留，取消不会自动重试。服务商已产生的 Token 无法撤回，服务商是否因连接断开而立即终止远端生成、以及最终计费方式，取决于其实现。

接口：`GET /api/items/<KEY>/term-reading?term=<术语>` 免费查询；`POST /api/items/<KEY>/term-reading` 使用 `{"term":"coronagraph","force":false,"repairOnly":false}` 按需生成/读缓存。`repairOnly:true` 永远禁止模型调用。
