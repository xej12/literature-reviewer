# Literature Reviewer · 文献梳理工具

**把 Zotero 中的论文，变成可以对照原文、逐步理解的阅读笔记。**

面向个人科研阅读的本地网页工具：不只给摘要，还能按需讲解研究方法、公式、专业术语和图表。解读保存在你的电脑上，再次查看可直接复用。

[新手安装](docs/installation.md) · [使用指南](docs/usage.md) · [常见问题](docs/troubleshooting.md) · [English](README.en.md)

> 支持 Windows x64。推荐下载 [新手安装 ZIP（已含 Poppler）](https://github.com/xej12/literature-reviewer/releases/latest/download/literature-reviewer-windows-x64.zip)，解压后双击 `setup.cmd`。仍需先安装 Python 3.11+ 和本电脑 Zotero；首次安装 Python 依赖需要联网。无需手动配置 Poppler/PATH，也无需 Codex、Node.js 或 Zotero 插件。暂不支持 macOS/Linux/Windows ARM64。

## 可以帮你做什么

| 你的需求 | 对应功能 |
| --- | --- |
| 从自己的文献库开始读 | 读取 Zotero 集合、元数据及本地 PDF；原始 PDF 可直接打开 |
| 理解论文在做什么 | 按章节生成阅读导览、方法拆解、公式讲解、实验与结论、局限与自检 |
| 不认识专业名词 | 专业术语表、结合本文的术语精讲、PDF 划词翻译 |
| 看不懂图表 | 左侧 PDF、右侧讲解；支持框选区域、翻页和放大 |
| 回到原文核实 | 来源片段与 PDF 页码定位，公式可展开原文对照 |
| 安排阅读顺序 | 本地阅读进度、研究目标、缓存的阅读优先级；可选导入中科院/JCR 指标 |
| 留下自己的理解 | 我的笔记（空白编辑）、文献关联、自动保存、Markdown/HTML 导出与浏览器打印 PDF |
| 保存不熟悉的内容 | 阅读中划词后存入“我的卡片”，在阅读工作台集中查看；卡片支持删除、提问、对话记录和手动总结 |
| 从一篇论文继续找文献 | OpenAlex / Semantic Scholar 查询、相似/前置/后续文献、来源链接、库内标记与缓存 |
| 少花重复费用 | 已存结果直接读取；卡片只有主动发送问题或点击总结才调用模型；重新生成需确认；关闭解析窗口会发出取消请求 |
| 跟进程序新版 | 右上角“软件更新”检查正式 Release，发行安装包可点击更新并自动重启；启动失败自动恢复旧程序 |

中科院/JCR 指标是第三方整理的指定年度数据，首次需单独导入。阅读等级围绕个人研究目标，不代表论文质量定论。

## 第一次使用，从这里开始

1. **准备 Zotero。** 在 Zotero 中确认至少一篇论文的 PDF 能打开。仅有云端附件时，先把 PDF 下载到本电脑。
2. **下载安装包。** 下载 [Windows x64 新手 ZIP](https://github.com/xej12/literature-reviewer/releases/latest/download/literature-reviewer-windows-x64.zip)，解压到普通可写文件夹，例如 `D:\tools\literature-reviewer`。不要直接在压缩包内运行。请在 Releases 选择这个文件，而非自动生成的 Source code ZIP。
3. **安装 Python 3.11 或更高版本。** 从 [Python 官网](https://www.python.org/downloads/windows/)下载安装，安装时勾选 **Add python.exe to PATH**，随后重新打开 PowerShell。
4. **一键安装并启动。** 双击解压后的 `setup.cmd`。它会创建项目自己的 `.venv`、联网安装 Python 依赖、校验并解压包内 Poppler，然后启动网站。无需管理员权限，也不会修改系统 PATH。

5. **打开网页。** 浏览器访问 <http://127.0.0.1:8765>。启动窗口需要保持打开；以后双击项目根目录的 `start.cmd` 即可启动。
6. **先验证文献，再配置模型。** 能看见文献并打开 PDF 后，点击右上角“模型设置”，填写自己的 API 地址、模型名称和 Key。Poppler 已由上一步配置好；图表解析还需要支持图片输入的模型。

没有 Zotero 或只想先试用界面时，可以运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Demo`。示例模式提供一篇内置题录和短示例 PDF，不读取本机文件、不连接模型；体验结束后按正常命令启动即可切回自己的 Zotero。

从 **Code → Download ZIP** 或 Git 克隆获取源码也可以双击 `setup.cmd`；源码不含 Poppler 二进制，会自动下载固定版本并校验 SHA256。普通 `start.cmd` 不会联网安装依赖。升级前请自行备份原目录中的 `data/`，安装包不包含你的文献和设置。

如果 `python` 命令找不到、Zotero 目录没有被识别，或不知道 API 地址怎么填，请跟着 [完整安装指南](docs/installation.md) 操作。上面命令无需激活虚拟环境，也无需管理员权限。

## 推荐阅读流程

新版工作台将文献库、我的笔记、我的卡片和联合查找放在同一导航中。首页显示已解读进度，文献详情分别呈现阅读工具、摘要、期刊指标和附件；窗口较窄时自动调整布局。

1. 点击“文献库”展开 Zotero 集合；再次点击可以收起集合。文献较多时，列表按页显示，使用底部的“上一页 / 下一页”浏览。
2. 打开一篇文献，先阅读原始 PDF，再按需要生成论文解读、术语精讲或图表解析。已经保存的结果会直接打开，不会重复调用模型。
3. 阅读解读或 PDF 时划选不熟悉的内容，选择“存入卡片”。卡片保存在“阅读工作台 → 我的卡片”，与笔记分开管理。
4. 点击一张卡片后，自己输入问题并点击“发送问题”才会调用模型。对话会保存在卡片中；点击“总结当前内容”才会生成总结，之后可以手动修改并保存到卡片表面。
5. 需要写自己的长篇理解时使用“我的笔记”。笔记是空白编辑器，不预设模板；保存、导出和删除都在笔记页面完成。

深度解读和术语精讲支持独立滚动的目录与正文，目录显示保存进度；点击“正文材料”可展开阅读范围与缺失提示。图表解析在大屏中左右对照，原图和讲解独立滚动，翻页按钮位于原图两侧；窄屏自动上下排列。划词菜单按“翻译 → 存入笔记 → 存入卡片”竖向排列，空间不足时显示在选段上方。

从源码更新后如仍显示旧界面，可按 **Ctrl＋F5** 强制刷新。Release 安装包对应各自发布版本；尚未打包的最新界面可通过仓库源码获取，更新前请备份个人 `data/`。

## 软件更新

从 **v0.4.0 起的新手安装包**开始，右上角提供“软件更新”。打开网站会检查正式 Release（自动检查最多每天一次）；发现新版显示提示，只有点击“立即更新”才会下载、校验并替换程序，不会偷偷安装。

更新前会先保存当前笔记；未保存的卡片总结、正在生成/保存/检索的任务会阻止更新。下载失败或校验不通过时继续使用原版本；替换失败或新版启动检查失败时恢复旧程序。请保持启动窗口打开，成功后页面会重新连接并刷新。`data/`、`.venv/`、已安装的 Poppler 和个人额外文件不会被更新器覆盖。

**v0.3.0 及更早版本需先手动升级一次**：备份旧 `data/`，解压带更新功能的新手包，将旧 `data/` 复制到新目录，再运行 `setup.cmd`。Git 开发目录只检查版本，不自动覆盖代码；源码 ZIP 没有发行清单，也需先换用新手安装包。未来若 Python 依赖或 Poppler 版本有变化，会提示按发布说明手动升级。详细步骤见[安装指南](docs/installation.md#9-升级与一键更新)。

## 费用、隐私和能力边界

- **本地运行：** 默认只监听 `127.0.0.1`。别人下载的是程序，需要在自己的电脑上连接自己的 Zotero；GitHub 不会托管你的文献网页。
- **模型费用自付：** 浏览、查缓存和免费整理已有答复不调用模型。主动生成和未命中术语表或缓存的翻译可能消耗 API 额度；“测试连接”只检查 `/models`，不生成内容。模型服务通常单独计费。
- **相关文献检索：** 支持单篇扩展，或选择 2–5 篇论文，围绕研究问题联合查找；附年份、综述、开放获取筛选、可撤销的“不感兴趣”和已存检索记录。不调用模型；主动检索向学术服务发送标识符、标题、摘要及研究问题，可能需要独立 Key 并受服务额度限制。结果保存后可直接复用。
- **推荐文献导出：** 勾选想读的候选，下载 RIS（可手动导入 Zotero）、BibTeX 或带关联依据及笔记模板的 Markdown 清单；只读已有结果，不调用模型。
- **外部模型会接收材料：** 生成论文解读、术语、图表、卡片问答或卡片总结时，相关论文文字、卡片摘录或所选页面图片会发送到你填写的服务。设置和阅读记录保存在本电脑 `data/`；通过界面保存的模型 Key 使用 Windows 当前账户 DPAPI 加密，检索服务 Key 仍以明文保存，请勿分享该目录。旧版遗留明文模型 Key 可在“模型设置”重新保存为加密格式。
- **忠于原文仍需核对：** 来源定位只帮助核实，不能保证模型解释正确。扫描件暂不支持 OCR，损坏的公式提取和图片识别可能出错。
- **取消存在服务商边界：** 关闭解析窗口会中断本电脑请求和上游连接；已产生的用量不能撤回，远端是否立即停算由服务商决定。

数据存储、备份与 Token 规则见 [使用指南](docs/usage.md)，具体材料覆盖和兼容限制见 [功能细节](docs/advanced.md)。服务尚无登录及多用户隔离，请保持本地使用。
